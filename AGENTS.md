# Repository Instructions

- Human contributors remain the authors and committers responsible for changes.
- When OpenAI Codex materially assists with a commit, append this trailer after
  a blank line in the commit message:

  `Assisted-by: OpenAI Codex`

- Do not use `Co-authored-by` for an AI tool unless its provider publishes an
  official GitHub account-linked identity and explicitly authorizes that use.
- Never invent an email address or reuse another product's bot identity for AI
  attribution.
